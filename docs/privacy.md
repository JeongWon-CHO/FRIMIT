# 개인정보 처리방침

Frimit(이하 "앱")은 아래와 같이 개인정보를 처리합니다.

최종 수정일: 2026년 8월 26일

## 1. 수집하는 정보

| 항목 | 수집 시점 | 목적 |
| --- | --- | --- |
| Apple 계정 식별자, 이메일 | Apple로 로그인할 때 | 계정 생성·로그인 |
| 닉네임, 아바타, 언어 설정 | 가입할 때 | 그룹에서 나를 표시 |
| 기기 종류, 알림 토큰, 알림 권한 상태 | 알림을 허용할 때 | 한도 알림·활동 알림 발송 |
| 하루 누적 사용 시간(초) | 그룹에 참여한 뒤 | 그룹의 공동 한도 집계 |
| 그룹·목표·기록(금액, 한 줄 메모), 활동 내역 | 앱을 쓰는 동안 | 서비스 기능 제공 |

Apple의 "이메일 가리기"를 선택하면 앱은 실제 이메일 대신 Apple이 만든 비공개 주소만 받습니다.

**앱 사용 시간은 총합만 전송합니다.** 어떤 앱을 얼마나 썼는지에 대한 목록은 iOS의 Screen Time(Family Controls) 권한 안에서만 다뤄지며, 기기 밖으로 나가지 않습니다. 서버로 올라가는 값은 그룹 기준의 누적 초 단위 숫자 하나입니다.

위치 정보, 연락처, 사진, 광고 식별자는 수집하지 않습니다.

## 2. 보관 기간

- 활동 내역: 14일 후 자동 삭제
- 하루 단위 사용량 집계: 90일 후 자동 삭제
- 원본 사용량 스냅샷: 7일 후 자동 삭제
- 그 밖의 정보: 계정을 삭제할 때까지

## 3. 계정 삭제

앱의 설정에서 직접 계정을 삭제할 수 있습니다. 삭제하면 로그인 정보와 프로필(닉네임·아바타)이 지워집니다.

다만 함께 쓰던 그룹의 공동 사용량 합계는 남습니다. 떠난 사람 때문에 남은 사람의 기록이 바뀌지 않도록, 그 합계에 연결된 기록은 "탈퇴한 멤버"라는 익명 표시로만 남으며 누구인지 알 수 없습니다.

## 4. 제3자 제공 및 처리위탁

앱은 개인정보를 판매하거나 광고 목적으로 제공하지 않습니다. 서비스 운영을 위해 아래에 처리를 위탁합니다.

- **Supabase** — 계정·데이터 저장 (미국)
- **Expo (Expo Application Services)** — 푸시 알림 발송 (미국)
- **Apple** — Apple로 로그인

이용자의 정보는 위 서비스의 해외 서버에 저장됩니다.
