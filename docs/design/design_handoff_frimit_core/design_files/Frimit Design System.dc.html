React Native 구현 노트
Bloom = 정적 이미지 또는 RadialGradient 1장
화면당 blur 레이어는 최대 2개. 카드 뒤 bloom은 expo-linear-gradient / react-native-svg의 RadialGradient, 또는 미리 렌더한 PNG로 처리하고 실시간 blur는 쓰지 않습니다.
Shared ring = SVG Circle strokeDashoffset
conic-gradient는 RN에 없습니다. react-native-svg의 원 + 그라디언트 stroke, 멤버 세그먼트는 dash 배열로 나눕니다. 애니메이션은 Reanimated로 strokeDashoffset만 보간.
Glass는 pill에만
BlurView는 그룹 pill, nav pill 등 작은 요소에만. 전면 blur와 다중 투명 레이어는 금지. 대부분의 서피스는 불투명 단색 + hairline border로 깊이를 만듭니다.
Dot texture = 타일 이미지
17px 타일 PNG를 ImageBackground로 반복합니다. 카드용 13px, calm용 22px 세 종류만 준비하면 됩니다.
