SYSTEM UI BOUNDARY
시스템이 소유하는 지점은 두 곳입니다. 알림·Screen Time 권한 시트(04·06), 그리고 앱 선택 picker(11 이후). Frimit은 그 앞의 이유 설명 화면과 뒤의 결과 화면(06a/06b, 12)만 디자인하고, 시스템 UI는 그대로 사용합니다.
ORBIT AS THE STORY
01의 궤도에는 빛 하나. 07·10에서는 점선 빈 자리. 08에서 내 자리가 비어 있고, 14에서 세 자리가 채워지고, 15에서 네 아바타가 모두 발광합니다. 15 → Today는 orbit이 축소·회전하며 Shared Pool 히어로 링으로 이어지는 하나의 동작입니다(Reanimated: scale + strokeDashoffset).
RN 구현 메모
궤도는 SVG Circle + 그라디언트 stroke, 아바타는 각도 → x/y 변환으로 배치(모두 동일 반지름). bloom은 화면당 1–2개, 정적 RadialGradient. 화면 전환은 opacity + translateY 12px 정도로 절제합니다.
